# MOMENT

MOMENT is a Web Design course project built with HTML, CSS, and JavaScript. It lets users discover events across Saudi Arabia, filter listings, and try a simulated ticket booking flow with downloadable QR code tickets.

## Run the project

1. Extract the ZIP file.
2. Open the extracted folder and double-click `index.html` to launch the site in your browser.

## Project files

- `index.html` — Main page and entry point.
- `styles.css` — Layout, responsive design, and ticket print styles.
- `events.js` — Event listings and image paths.
- `app.js` — Page rendering, search, filters, and user interactions.
- `booking.js` — Demo accounts and booking logic.
- `qr.js` — Ticket QR code generation.
- `images/` — Local event photos.

Bookings and payments are simulated. Demo accounts and bookings are saved in your browser. Remotely hosted images and fonts require an internet connection
